## 5. One ultimate-minimal plan, rejected ideas, and build

The design composes existing primitives; it adds no new learner, model, weights, network runtime, or knowledge house:

1. `learn_or_read_v1.decide` first → `READ_ONLY__NO_STORE_WRITE` when the live instruction determines the action.
2. Deny caller-supplied authority bits and raw path/argv/content/trace/answer/reward/outcome store payloads.
3. `applicability_v1.insufficiency_witness` refuses same-state opposite outcomes and impossible separation; stale dynamic versions require fresh observation.
4. For a named missing goal fact, `active_question_v1.ask` / `settlement_v1.settle` operate only on a closed reachable regime space. Outside-space, open-space, blind-instrument, and underdetermined outcomes refuse.
5. Otherwise `contrast_selection_v1.select_contrast` requires an informative reachable contrast; `perfect_algorithm_v1.generalize/admit` must reach the goal on **all** offered fresh instances (stricter than `admit`’s any-instance criterion). Only a hashed mechanism signature, goal/environment scope, relation signature, artifact span, evidence digest, and admission counts are stored.
6. The external store is inspectable/removable/restorable/digest-stable. A different-code `python3 -I` local process recomputes decision classes, canonical digests, store cleanliness, editability, run refs, and false authority fields. It is local recheck, not independent attestation.
