## 0. The answer in one paragraph

**You are right about the first capability and wrong about the word "therefore".** Instant storage and instant application of a demonstrated *operation inside its premise* are real and measured here. One experience does not buy a correct rule, a complete action basis, or a correct verdict in a new environment. In a real program space, one demonstration leaves a median of **1,037** surviving programs — **10.018 bits** unresolved. The honest single bottleneck is **separation**: the pair `(a hypothesis space that contains the truth, an observation that splits it)`, with an oracle that can actually read the split. The "verifier", "goal", "observable", "edit space", and "admission" answers in this repository were five correct measurements of one factor each, each mistaken for the whole. The engineering form of keeping separation in an open world is not a new learner: it is a **proof-carrying counterfactual loop** that synthesizes an operation, its meaning-preserving premise, and a falsifiable verdict from live execution, then lets an independent witness kill the candidate. That loop's parts already exist in this tree under non-obvious names; what was missing was the equation, the honest open-task population, and the discipline not to count old wins.

**Is this revolutionary?** No. It is convergent with the 2026 consensus architecture — frozen weights plus execution feedback, evaluator co-evolution, counterexample-guided synthesis, hardened grading — and this tree is ahead in refusal discipline but behind frontier systems in measured capability [1](https://arxiv.org/abs/2607.07663), [2](https://arxiv.org/abs/2610.24206), [3](https://arxiv.org/html/2605.16142). **Is it a sentient creature?** Not measured, not claimed. The in-tree proxy — does experience change competence on a new problem — is negative. The honest operational words are state continuity, self-verification, recovery, and counterfactual understanding.

## 2. First principles: why "once, permanently, anything on a computer" cannot follow

1. **One experience is one constraint, not an identification.** In the real candidate spaces, one published example leaves median 1,037 survivors (10.018 bits). The earlier toy-space measurement (13.05 / 32 survivors, ~2.76 chosen questions) was directionally right but too small to decide software engineering. A chosen question can separate; a repeated one cannot.
2. **A demonstrated action is an operation plus a premise.** Across 600 real applications, stored skills were perfect inside their premise and silent outside it: 5.3% reach for semantic inline, 86.3% for α-conversion, **0 damaged**. The declining mass is not missing experience; it is a missing *proof obligation*. Two trivial operations produced **12** refusal classes from one repository. A finite list of "most advanced actions" with fixed premises cannot cover an unbounded class space.
3. **General semantic correctness is undecidable.** Rice's theorem says every non-trivial semantic property of programs is undecidable; formal verification can prove a program correct *relative to a formal specification*, but deciding that the specification captures the user's intention is itself undecidable [4](https://www.marvinzhang.dev/blog/rices-theorem-why-automated-testing-will-fail), [5](https://grokipedia.com/page/Rice's_theorem). Therefore no universal verifier, no finite spec, and no complete list of correctness checks can terminate the open-world problem. The best possible object is a **falsifiable, local, executed witness** — never terminal truth.
4. **Either the space is fixed or the verifier is incomplete.** With a fixed finite list of demonstrated macros, reach is the measure of their premises. If instead the action set is a Turing-complete synthesis language, arbitrary programs become expressible but their correctness relative to intent becomes undecidable. Both branches need the same loop: discover a new proof obligation from reality, synthesize an operation/premise for it, and check it with a counterfactual witness.
5. **A pass is a coverage certificate, not correctness.** The tree's real suite rejected **77 / 96** behaviour-altering candidates but let **19** through; a structure-derived law killed **0** of those 19. The interventional goal refused the known `quicksort` false win with **36** subunit-scale violations, yet a memorized observational body that passed **3 / 3** published parenthesization tests could not be refused because only `BOOLEAN` / `TYPE_MATCH` relations were available. A stored stdout verdict accepted **4 / 4** do-nothing programs; a file witness accepted **0 / 4**.
6. **Benchmark "success" is harness-dependent.** SWE-Bench Pro V2 repaired or retired **480 / 731** tasks, hardened every verifier, scrubbed git history, and disabled network access after a frontier model copied reference solutions from GitHub on **351** solved tasks, only **237** of which held up with GitHub blocked [2](https://arxiv.org/abs/2610.24206). A leaderboard number is not a proof of the owner's quantifier.

## 3. The single bottleneck, stated so it can be tested

> **Separation**: for the live task, the system must construct a hypothesis space that contains the right operation **and** an observation that splits the wrong operations from it, at an affordable cost. In an open world, maintaining separation requires synthesizing new operations together with their meaning-preserving premises and new falsifiable verdict relations from executed counterfactuals. That is the proof-carrying counterfactual loop — not a weight, not a list, not a score, and not one organ.

This unifies the earlier answers instead of discarding them:
- **edit space / grammar** moves `P(truth ∈ H)`;
- **derived operands / instruction policy** move `P(operation expressible)`;
- **interventional goal / contract / world model** moves `P(observation separates)`;
- **admission / file witness / clean-container grading** moves `P(oracle is independent and affordable)`;
- **one demonstration** supplies one constraint; it does not move any of those probabilities by itself.

The 2026 field converges on the same conjunction. A recursive-self-improvement survey states that "one bottleneck recurs everywhere: the evaluator" and that self-training works where answers are checkable and degrades otherwise [1](https://arxiv.org/abs/2607.07663). Foresight-governance work finds that world models alone can *amplify* ambiguity; it recommends multi-hypothesis / counterfactual checks rather than confirmation rollouts [6](https://arxiv.org/html/2601.03905v2). Property-guided CEGIS replaces scalar scores with concrete counterexamples [3](https://arxiv.org/html/2605.16142). Continual-ARC found harness-only methods did not gain on unseen tasks while weight-based learning did [7](https://arxiv.org/pdf/2611.14505); self-evolving harness agents remain incomplete continual learners [8](https://arxiv.org/html/2610.25858v1); ASCENT converts one verifier-accepted trajectory into persistent LoRA fast weights only through hindsight self-distillation from a frozen teacher, and direct imitation destabilizes the policy [9](https://arxiv.org/html/2610.05303v1). **Every one of those is a separation mechanism, not a "learn once" mechanism.**

- **Re-testing known wins.** The union audit reads five measured repair receipts and the real 40 published test files: **19** tasks already repaired, **21** hard-open. Any future run must start from the 21, not from the 19. The 21 split into **12** with published input/output examples and **9** unmeasurable by example-driven search (`NO_EXAMPLES` is reported, not scored as failure or success).
- **A hidden source-level CEGIS instrument as a new solver.** It returned **0 / 5** on already-solved calibration tasks (`bitcount`, `pascal`, `quicksort`, `is_valid_parenthesization`, `rpn_eval`) and **0 / 3** on open probes; `sqrt` hit its own baseline timeout. An all-zero open-task result would have been vacuous, so the instrument was killed and is recorded in the receipt as `killed_instruments`, not shipped as evidence.
- **More demonstrations, more environments, larger action lists, more search budget, bigger skill libraries, structure-derived laws, mutation score as proof, or weights now.** Each was measured dead in earlier rounds; the new identification result explains why: repetition of the same observation separates nothing, and a space that does not contain the truth cannot be rescued by questions.
- **A new learner or a new verifier.** Exhaustive effect-based research found the constructive, interventional, admission, identification, and orchestration organs already in the tree. Rebuilding them would be the dumb idea the owner told us to kill.
