## 2. What the frontier did (web research, Nov 2026, under unfamiliar names)

### 2.1 Instant learning (LaCT / LaCET / TTR / MesaNet / Gated DeltaNet-2 / delayed supervision / active inference / LILO-Stitch / Absolute Zero)

- **Large Chunk Test-Time Training (LaCT, arXiv:2505.23884, ICLR 2026):** Updates nonlinear SwiGLU fast weights over 2K–1M-token chunks with Muon online optimizer; fast-weight state to 40% of model params at 70% GPU utilization in dozens of lines of PyTorch. Token-by-token TTT was <5% utilization. [1](https://arxiv.org/html/2505.23884v1) [3](https://arxiv.org/abs/2505.23884)
- **Elastic TTT (LaCET, arXiv:2604.07350):** EWC Fisher-weighted elastic anchor so fast weights don't overwrite earlier chunks across infinite streams. [5](https://arxiv.org/html/2604.07350)
- **Test-Time Regression (TTR-Compressor, arXiv:2610.31574), MesaNet, Gated DeltaNet-2 (arXiv:2605.22791):** Linear attention as closed-form dual ridge/conjugate-gradient regression in the forward pass; decoupled erase/write; 55.6% fewer tokens. [2](https://arxiv.org/html/2610.31574v1)
- **Delayed Supervision (arXiv:2609.32312):** Next-token prediction doesn't teach retention across 10K-token gaps; delayed QA probes during outer training lift LaCT +5.48 pts on BABILong with zero test-time labels. [4](https://arxiv.org/pdf/2609.32312)
- **Active Inference / EFE / Optimal Question Asking (arXiv:2608.19202, 2512.21129, 2607.25131):** Clarifying questions/probes/tool calls as Expected Free Energy minimization; deterministic epistemic value = Expected Information Gain per token/action. [1](https://arxiv.org/pdf/2512.21129) [2](https://arxiv.org/html/2608.19202)
- **LILO + Stitch (arXiv:2310.19791):** LLM proposal + Stitch branch-and-bound λ-abstraction compression (1,000–10,000× faster than DreamCoder) + AutoDoc (anonymous abstractions hurt reuse −30%; documented abstractions compound). [1](https://arxiv.org/pdf/2310.19791) [3](https://arxiv.org/html/2310.19791v2)
- **ARC-AGI-3 reality check (arXiv:2607.15439):** Single Codex agent with persistent Linux Python workspace completed 183/183 public ARC-AGI-3 levels with 41% fewer actions than humans, writing ad-hoc Python online without rigid DSL. Flexible workspace code synthesis beats narrow fixed DSLs. [2](https://arxiv.org/pdf/2607.15439)
- **Brain's position:** Retention (exact, reversible, no forgetting) beats all of the above; identification (which hypothesis, which vocabulary, which composition) is the open problem. LaCT/LaCET solve retention-in-weights; Brain solves retention-in-store. The missing layer is cross-kind abstraction, which neither solves.

## 3. Synthesis: what the frontier proves and what it doesn't

The frontier proves: (a) retention-in-weights (LaCT/LaCET) still needs a base model + GPU + verification signal; (b) interface evolution (Agent S4) beats model scaling for computer use; (c) proof-or-it-didn't-ship (vericoding) beats string guessing for coding; (d) external memory (BiSpace, Agent Zero) beats weight editing for continual learning. None of these solve cross-kind abstraction (0/4,444) or the observability/expressibility gap. Brain's asymmetric play — external symbolic store + compiled fast path + effect-oracle verification — is validated by (b), (c), (d) and constrained by (a). Wave 47–48 builds exactly that play.
