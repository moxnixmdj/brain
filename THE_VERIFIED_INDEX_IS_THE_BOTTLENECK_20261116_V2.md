## 0. The answer in one paragraph

**No.** Instant learning is real as permanent **storage**, not as permanent identification of a general rule. Instant learning in a new arbitrary environment is real as a **cost law** for measuring `(action × state class)` effects, not as a proof that one trace teaches the environment. Giving the smartest coding actions once does not produce the most advanced coding agent on the planet, and doing every computer action once does not solve all computer use. The three blockers the owner named are not three independent bugs: they are three projections of one necessary condition — **a verified index**. A hypothesis space must contain the truth; the index must contain the causal observable that splits the survivors; a grounded proposer and an independent verifier must read that split; and a fresh proof on the state in hand must license action. If one high-leverage shared defect must be named, it is the **index/specification with a frame**, but it is **not a single sufficient lever**. The fastest path is not more demonstrations, more environments, bigger action lists, conventional weights, or a new learner. It is: reuse the existing organs, keep facts in zero-weight instant knowledge, admit **zero new parameters** until every bit is calculated from live causal evidence and passes a hard-open verifier gate, and test only the real hard-open population. No sentience, terminal truth, benchmark, family-rank, or solved-everything claim follows.

## 2. First principles: why “once, permanently, anything on a computer” cannot follow

Let `H` be the representable hypothesis space, `I` its invariant closure, `s` the state in hand, `O` the causal observations the system can execute, `V` an independent verifier, `P` a grounded candidate proposer, and `F` a frame predicate saying what must not change. A one-shot trace `t` can become permanent **storage**. It licenses action only when all of these hold:

```text
∃ h* ∈ H(I, failure_evidence)          truth is representable
∧ key(s, o) is injective on h* vs h′    the index contains the policy-relevant split
∧ o ∈ O is computable/affordable        a causal observation can split survivors
∧ P(s, o, F) proposes a grounded edit   synthesis is not replay of seen syntax
∧ V(o, h*, F) reads the split           an independent verifier can judge it
∧ proof(s) is fresh                     state drift did not invalidate the premise
```

If any factor is zero, more demonstrations, environments, actions, compute, and “advanced coding work” multiply by zero. This is not a claim about effort. It is a claim about information: one answer from the world cannot uniquely identify a rule when multiple rules produce that answer. The project’s four-levers measurement makes this arithmetic: `5.5546` bits before one demonstration, `3.8176` bits after it, `0/10` exact identifications, and `10/10` settled after `2.0` chosen questions. The `log2(|Y|)` ceiling did not bind; the missing split did.

**Operational understanding** is therefore not “pattern matching” and not a philosophical consciousness claim: it is the ability to answer differently under a real intervention in a novel state, with a causal observation that separates the candidate mechanisms and a verifier that can read that separation. Where no such observable exists, the honest output is `UNDECIDABLE`, not a confident rule.

## 5. What is the single bottleneck?

**Strictly: there is no single sufficient bottleneck that unlocks “most capability” in the claimed terminal sense.** The measured remainder is a conjunction. But if one highest-leverage shared defect must be named, it is:

> **The verified index/specification:** the function that decides which lesson, edit, or action applies must contain the observable the policy depends on; the goal must carry a frame saying what must not change; and an independent verifier must read the resulting split on the state in hand.

Why this is the right single answer without granting the false quantifier:

- It is shared by identifiability, vocabulary insufficiency, and synthesis–verification asymmetry. Fixing it removes the common reason all three fail.
- It is shared by the skill store, lesson ledger, cross-language proposer, GUI phrase gate, code-repair template, and any future calculated parameter. Fixing the edit space fixes one; fixing the index fixes the routing of all of them.
- It is still **necessary, not sufficient**: the proposal generator for unpassed bugs, the per-step long-horizon verifier, effect vocabulary for new machine shapes, and scale of the `(atom × state class)` table remain open.
- The latest main receipts falsify every one-lever substitute: GUI invariance has `4/5` quotient-zero judges; proved composition reaches `31/80`; finer feature grids leave `0` usable key families; one `id` binding is a local A/B fix; replay goes stale `122/228` times.

So the smartest answer to “what single bottleneck?” is: **do not hunt a single lever; fix the verified index first because it is the shared necessary condition, then keep the conjunction enforced.**

## 7. Weights, instant knowledge, and “the best part is no part”

The owner is not opposed to parameters; the law is stricter: **every bit in those parameters must be calculated, and parameters must never be a knowledge house.** This branch obeys that law by adding **zero new parameters**.

```text
b = C(s, o, I, V)
```

A parameter bit `b` is admissible only if:

1. `s` is the current state and `o` is a live causal observation, not a stored claim;
2. `I` is an invariant closure so the bit is not keyed on a spelling or surface accident;
3. `V` is an independent verifier that reads the split;
4. `C` is a deterministic calculated function from our own execution evidence, not conventional pretraining and not an external model’s weights or outputs;
5. the candidate bit gains on real hard-open targets, breaks zero archived solved behavior, and survives a fresh proof on the state in hand;
6. facts remain in the content-addressed instant-knowledge model, where they are inspectable and deletable.

If any condition fails, `b = 0`. That is “the best part is no part” in its exact engineering form.

Why zero weights now is the fastest path, not an ordinary compromise:

- `THE_WEIGHT_LAYER_NEEDS_A_GATE_TOO_20261113_V1.md`: `32/32` naive weight updates certified themselves successful, final agreement was `5/32`, `3` correct predictions broke, and the shipped gate admitted only `1` while refusing `31`.
- `WEIGHT_SPACE_FUEL_20261113_V1.json`: `ready_to_train=false`, `64` verified units against `5000` minimum units to try; execution receipts and trajectory stores have no independent pass/fail signal.
- `WHY_WEIGHT_SPACE_IS_NOT_THE_MISSING_LAYER_20261112_V1.json`: same-kind one-demo transfer recovered `493/1674` non-import changes; another-kind transfer recovered `0/4444` and all `19` attempted changes were wrong. Weights trained on that data would learn the same thin signal.
- The project’s existing `weight_update_admission_v1.py` already applies a candidate step to a copy of the heads and measures transfer/archive agreement before allowing persistence. It is reused, not rebuilt.

**Instant knowledge connection:** the zero-weight content-addressed model is the knowledge source; the calculated-parameter layer is empty until a bit passes the gate. This preserves efficiency and avoids years of fake work. It does **not** claim perfect weights, a perfect model, a sentient creature, or terminal truth. If future weights are built, they are built from scratch as calculated bits from our own live evidence, not by using an external model or conventional pretraining.

## 8. Sentience, “understanding everything”, and frontier models

Nothing in this branch measures sentience or creates it. A creature that learns instantly is not thereby sentient, and a system that conflates mechanism with experience optimizes the wrong number. The owner’s goal of literal understanding is operationalized here as **counterfactual competence**: given a novel state, name the intervention whose outcome would differ, execute or prove it under the frame, and let an independent verifier read the difference. That is measurable; “understands everything” and “sentient” are not.

Frontier 2026 systems did not “solve all of those problems.” They improved by combining frozen models with harnesses, execution feedback, persistent state, and verifier-gated admission; long-horizon computer use, benchmark contamination, verifier disagreement, and protocol shortcuts remain open. Public research is useful evidence, not authority. We did not call, embed, or distill from any external model. Reading a paper and deriving a first-principles law is allowed; using a model as reasoner, teacher, or capability provider is refused.

## 12. Smartest ordered plan

1. **Do not build weights, a new learner, a new verifier, or a new planner now.** Reuse the organs in Section 3.
2. **Keep zero new parameters.** Facts stay in instant knowledge; every future bit must pass `C(s,o,I,V)` with hard-open transfer, falsification, regression-zero, and fresh-state proof.
3. **Author the hypothesis space and frame before spending interactions.** Convert intentions into predicates with `F`; choose observations that split survivors.
4. **Name the missing observable, not a finer grid.** Add executed-function, callee-signature, runtime-traceback, content-field, or relation observables only when a real failure shows the index key is non-injective.
5. **Generate proposals from live failure and verify by execution.** Use predict–prove–act; compose only steps whose premise and proof survive effects.
6. **Run only hardest real open tests.** No synthetic tasks, no known wins, no external model, no network at run time, answer keys absent, test bytes hashed, every published node id collected and invoked, timeouts isolated, failures reported.
7. **Admit one calculated bit only after the gate.** If no such bit passes, zero remains optimal.
8. **Merge once when the complete feature and signed referee are green.** No duplicate PR, no `--admin`, no force-push, no workflow/check-run tampering.

**Authority NONE.** Producer-run sandbox, one machine. Independent reproduction is open. This answer does not register capability, solve computer use, prove correctness, claim independent verification, claim sentience, or authorize terminal credit.
