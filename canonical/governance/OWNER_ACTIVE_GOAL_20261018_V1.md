## 1. What I want (owner's words, 2026-10-18)

What I want is that **the machine can do anything on the computer by itself**, and the
learning must be **instant** — not in days, or tomorrow, or whatever.

For example, if I give it an ambitious goal, like **"Make me a million dollars,"** the machine
must **calculate the fastest way with minimal actions** that is going to give me the output
that I want.

It will make this prediction based on all the data that it needs. Most of the data that it
needs, **it obviously doesn't have**, so it must, **by itself**, say:

> "I don't have the data, so I must figure out the fastest way to get this data."

After it gets the data, **the data must be complete.** If it just makes the prediction on just
some data, it will probably extrapolate: *"This is the fastest way based only on the data that
it has."* There are a lot of better and faster ways that **it doesn't know anything about**,
because it doesn't have any data about those ways or those things at all.

**It must know literally all the data, and everything must be done in the fastest way.**

All the time, all it does is think about **how to reach the goal in the fastest way with
minimal actions**.

## 2. The goal must actually be completed

The goal must be done as it should, and must be **completed as the goal was put in the first
place**. If the goal is $1 million, it should make it — so it will **not stop till it really
hits the goal**, hits the $1 million. **It can't stop at $100 or whatever.**

## 3. Global extrapolation — the mistake it must not make

This is the owner's own worked example, and it is the sharpest statement of the requirement.

Suppose that after it gets the first pieces of data, it asks "what is the fastest way?", and
those pieces are like this: somebody wrote a paper on the internet that says **the fastest way
is to make YouTube videos.**

If this is the only source that it knows about, **it will extrapolate that the fastest way is
YouTube videos** — and that this is the fastest way — **just from the data that it knows**, and
maybe the data that it read.

So it will conclude something like:

- the first / best way to hit $1 million is **YouTube videos**
- the second best way is **faceless TikTok videos**
- the third fastest and best way is **being an influencer on Twitter**

It will extrapolate that **the fastest and best way is just YouTube videos** — and
**this is a huge mistake**, because the world is very wide and very big, literally huge.
There are a lot of opportunities everywhere, and there are a lot of **hidden opportunities
nobody knows about**.

**It must figure out the best way to get all the hidden data, or all the data that it doesn't
know, or that is not obvious.**

Its extrapolations must be **global all the time**, not based on just one piece or small
pieces of data. This is a huge mistake here.

## 4. The closing statement

What I wanted must be **totally independent**, by itself, **planning and calculating all the
time the fastest way to do anything**. Even the planning itself must be **insanely fast**.

**Everything must be insanely fast, and it must extrapolate globally.** Everything — or every
extrapolation it does — must be global, not only on some little amounts of data.

That's all what I want. It must **keep going, keep planning by itself, and be totally
independent**.

> **"I want it sentient and I want everything instantly. This is what I want."**
