## Core mathematical formulation

For a fixed Brain substrate S and target capability set C, minimize the unique persistent dependency closure, not capsule-local advertised bytes.

Resource-bounded joint capability description:

[
B_R^*(C \mid S)
=
\min_R
|\mathrm{closure}(S+R)-\mathrm{closure}(S)|_{\text{unique persistent bytes}}
]

subject to:

- every required target capability remains >= its accepted frontier bar;
- exact donor deletion succeeds;
- hidden base/model/service dependencies are counted;
- held-out qualification passes;
- non-target interference remains within the accepted bound;
- latency, memory, compute, and reliability constraints remain acceptable;
- JIT knowledge is not counted as permanently internalized capability.

For multiple mechanisms, count shared artifacts exactly once.

Marginal cost of capability i:

[
\Delta B_i = B(C_{1:i}) - B(C_{1:i-1})
]

Terminal cost:

[
B_{terminal}=B(C_1,\ldots,C_n)
]

Acquisition order may change marginal cost; terminal union does not.

## Required accounting split

Also distinguish:

## Search order

Always search in this order before retaining new learned bytes:

1. zero-byte reuse/composition from already-owned Brain mechanisms;
2. deterministic or symbolic route;
3. tiny control/routing key;
4. sparse/low-rank delta or expert selection on an already-owned substrate;
5. compact residual learned module;
6. white-box donor circuit/module;
7. larger route only if smaller classes fail.

This is the ELICIT-BEFORE-TEACH rule.

Recent EDL-style research is useful only as a search signal for latent-vs-taught behavior. EDL is NOT a proof of minimum deployed capability bytes.

## Counterexample-guided minimization

Use a CEGIS-like loop:

1. start with the smallest candidate representation;
2. evaluate against protected/adversarial verifier;
3. obtain the smallest counterexample;
4. add only the mechanism necessary to close that witness;
5. recursively delete/recompress everything;
6. repeat until qualification closes or a residual is preserved.

For learned/agentic behavior: teach only the earliest irreducible missing transformation, then rerun before teaching later steps.

- a specialization is rejected if it saves negligible bytes while worsening latency;
