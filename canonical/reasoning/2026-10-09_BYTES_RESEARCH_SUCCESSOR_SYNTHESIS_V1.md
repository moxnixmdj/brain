## 1. Exact research question

After bulk parameterized knowledge is removed from the permanent architecture and task knowledge is retrieved JIT, what is the **minimum persistent information Brain must own to retain the full required capability envelope**?

The donor may be a neural model, library, framework, skill pack, prompt policy, or any other inspectable implementation. Historical packaging has zero authority. The target is the smallest **resource-feasible, donor-independent, Brain-owned executable causal closure** that still meets the required behavioral bar.

A useful conditional formulation is:

[
\Delta B(C\mid S)
=
B(\mathrm{closure}(S+R_C))
-
B(\mathrm{closure}(S))
]

where (S) is the already-owned shared Brain substrate and (R_C) is the new residual for capability (C).

For the full capability set:

[
B_{terminal}
=
B(\mathrm{unique\ closure}(S,K,Q,R_1,\ldots,R_n,D))
]

where (K) is any empirically justified shared cognition substrate, (Q) routing/control, (D) required decoders/loaders, and (R_i) capability-specific residuals.

This is **not** the sum of independently minimized capsules because shared machinery must be counted once.

## 2. Critical correction: resource-bounded, not raw shortest description

Raw shortest-description optimization is pathological. A tiny program could reconstruct or search an enormous capability while consuming unacceptable time or compute.

Therefore Bytes is subordinate to the parent mission:

1. correctness/capability bar first;
2. acceptable wall-clock, reliability, memory, compute and verification cost;
3. hard $0 incremental spend;
4. then minimize persistent capability information.

A storage reduction that materially worsens mission wall-clock without compensating value is not a win.

## 3. Required accounting split

Do not mix these:

- **operative capability bytes:** load-bearing persistent mechanisms;
- **online verifier bytes:** runtime correctness machinery that is itself load-bearing;
- **historical proof/evidence bytes:** receipts, logs, old experiments; durable but not cognition unless runtime-required;
- **candidate warehouse bytes:** unpromoted donors/candidates; not terminal owned capability;
- **transient JIT information:** task-scoped semantic/factual information that may be arbitrarily large but is discarded after use;
- **fixed general substrate:** interpreter/OS/general computation substrate may be excluded only under an explicit conditional metric and must remain disclosed.

Content-addressed identical blobs count once.

An advertised 2 MB adapter that requires a 40 GB capability-bearing base is not a 2 MB capability.

## 4. Search strategy

### 4.1 Elicit before teach

Before retaining new learned information, test whether the behavior is already latent in an owned substrate and can be activated by:

1. zero-byte reuse/composition;
2. deterministic procedure;
3. tiny routing/control key;
4. sparse/low-rank residual;
5. small specialized module;
6. white-box donor slice;
7. larger residual only after verified failure.

Generalizable-information / EDL-style measurements may be useful **search signals** for “elicitation vs teaching,” but they are not proofs of deployed minimum bytes.

### 4.2 Bidirectional search

Search from both directions:

- **bottom-up:** zero bytes → tiny explicit mechanism → small residual → larger module;
- **top-down:** full donor → delete modules/branches/precision/context/scaffolding until further deletion breaks the contract.

Use one verifier. The best valid route wins.

### 4.3 Counterexample-guided byte minimization

Start with the smallest candidate representation. On a verified failure, retain only the mechanism needed to close that counterexample, then re-minimize globally. Final qualification must remain untouched.

### 4.4 Global mechanism cover

Treat Brain's atomic causal contracts as the universe to cover. Candidate mechanisms are hyperedges with:

- covered behaviors,
- dependencies,
- unique compressed bytes,
- latency,
- memory,
- compute,
- reliability,
- verification cost.

Then find the minimum-cost verified dependency closure. Exact branch-and-bound or admissible-bound search can certify optimality **over a finite enumerated mechanism set**. Do not upgrade that to a universal information-theoretic minimum.

## 10. Key deductions

1. **Parameter obsolescence generalizes to dependency obsolescence.** Models are not special. Libraries, frameworks, skills and prompt packs also contain historical packaging baggage.
2. **A capability may have zero marginal persistent bytes** when it composes entirely from already-owned mechanisms plus JIT knowledge.
3. **Global factoring dominates independent capsule minimization** whenever multiple capabilities share causal machinery.
4. **The true unit is unique dependency-closure information**, not file count, path bytes, parameter count, adapter size or repository size.
5. **Compression is valid only with decoder/substrate boundaries disclosed.**
6. **Donor packaging has zero authority.** Retain only load-bearing causal branches.
7. **Candidate warehouses must not inflate terminal capability byte counts.**
8. **EDL/generalizable-information ideas are search guidance, not runtime minimum-byte proofs.**
9. **Global exact Kolmogorov minimum is not the default claim.** Use best-known verified upper bounds or exact minima over finite enumerated representation sets.
10. **A generic tiny cognition kernel is a hypothesis, not an axiom.** The Brain already falsified simplistic “one small judge” thinking elsewhere; shared substrate must be earned empirically.
