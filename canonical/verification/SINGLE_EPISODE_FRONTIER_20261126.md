# What the frontier comparisons actually test

Evidence boundary as of **26 Nov 2026**. This is a comparison of tasks, interventions and denominators, not a composite leaderboard. The other systems' scores do not belong to Brain. The interesting comparison is **what resource paid for the missing information**.

| Question | External evidence | Consequence for Brain |
|---|---|---|
| Is acting in fewer steps the same as acquiring a new game? | The public ARC-AGI-3 study compares the same coding agent with textual notes, executable models, simplification and verification. At max effort even the textual variant completed **all 183 public levels**, using **41% fewer** total actions than the summed human baseline. The verification treatment scored better at lower effort, with markedly different token costs. [1](https://arxiv.org/html/2607.15439) ARC Prize separately reports Astra below the median tested human's action count on **96%** of evaluated levels, and markedly different cost and scores for standard vs provider-adapter harnesses. [1](https://arcprize.org/blog/astra) | Exact readback is useful, not a theorem that executable models are necessary or sufficient. Our five actions followed **one already-solved level**, after paying seventeen actions for the teacher. Report actions, paid resets, wall time and storage, not just replay latency. It is neither a 183-level completion result nor a private-competition score. |
| When is a screen abstraction sound? | Identifiability results for near-deterministic endogenous dynamics come with assumptions about dynamics, coverage and nuisance variation; single-step inverse-dynamics representations can over-abstract. [1](https://arxiv.org/pdf/2110.08847) Delta debugging reduces an input by **running and checking** a candidate, not by proving independence from a trace that happens not to change. [2](https://arxiv.org/abs/cs/0012009) | Treat picture equality as a search key. A hidden counter can change on identical pictures. Keep failed predictions, spend, terminal signal, and a way back to cold exploration. Use distinct goals and levels as the denominator when claiming transfer. |
| Is the model closing the coding gap? | SWE-bench Pro V2 re-audited task specifications and uses clean-container patch regrading. Best reported full-set success is **99.4% on 642**; on the **51 Hard** split the reported systems range from **52.9% to 98.0%**. [2](https://arxiv.org/abs/2610.24206) FeatureLoop instead measures incremental requirements with cumulative acceptance checks: 61 tasks from 34 repositories; **85 of 147** later requirement groups depended on new information or discovery. [1](https://arxiv.org/html/2610.35488) | A search procedure cannot deduce a user's unexpressed future preference. Ask for the smallest input/output distinction when a truthful source is available; don't read the hidden test. Require a real patch and a receiver grade. FeatureLoop is an attractive future *preservation* test; inspecting the paper or doing two blank CP1s is not a FeatureLoop score. |
| What is a terminal or desktop success? | TB 4.1 strengthened grader isolation and corrected false negatives **and** false positives: 89 and 45, out of 11,550 regraded trials (~1.16% changed). [1](https://www.tbench.ai/news/terminal-bench-4-1) OSWorld 2.0 has **108 end-to-end workflows**, not 108 individual tool calls. [3](https://arxiv.org/pdf/2606.29537v1) The S4 paper reports **21.3% binary** for Qwen3.8-27B with evolved interfaces on those 108, which **include its 15 validation tasks**. [1](https://arxiv.org/html/2610.28601v1) | A green exit, matched call, valid JSON or accessible DOM node isn't the requested effect. The earlier Doors UI/no-op controls are useful because they re-read location. Our room has an indexed frame and actions, not a desktop. No signed OSWorld result, no fresh TB 4.1 image run, no substitution of TB 4.0 comparisons. |
| Does the memory store help when wording changes? | LoCoMo-Plus targets an implicit constraint under a **cue–trigger semantic disconnect**, graded on response-level consistency; string matching and prompted task labels can mismeasure it. [2](https://aclanthology.org/2026.acl-long.1150/) MemoryAgentBench separately challenges incremental retrieval, test-time learning, long-range understanding and conflicting/updating information. [2](https://arxiv.org/abs/2507.05257) | Finding the exact cue in our contrast pool is directly checkable, but is not the response task. The lexical/fusion results are poor even with all 394 distinct cues retained. No MAB score: its [code snapshot](https://github.com/HUST-AI-HYZ/MemoryAgentBench/tree/538026089d1a8a8eff05121d0db89b388f360eba) and input schema, not test execution. Next require an independently checked answer supported by the selected source, then a contradiction/retraction that changes it. |
| Is an external store equivalent to learning a model? | BiSpace separates retrieval in an external semantic representation from injection into an **existing model's hidden representation**. It reports per-entry storage about **10.2%** of its comparator and sequences up to **16K edits**; the encoder itself has a fixed cost. [1](https://arxiv.org/abs/2611.25861) [2](https://arxiv.org/pdf/2611.25861) | Retrieval, latent injection and adapter training are different interventions. We ran no encoder/inference, trained no weights, and got no BiSpace accuracy. The external SQLite lesson and the PR's LoRA-size manifest are neither learned weights nor evidence of zero interference. |
| Can the system promote arbitrary self-edits at a guaranteed risk level? | Sequential testing with optional stopping can use products of **conditional** e-variables (or suitable nonnegative supermartingales). The expectation constraint is under the null **given the history**, not merely a marginal average. [2](http://proceedings.mlr.press/v146/grunwald21a/grunwald21a.pdf) | A syntax check, a selected-test pass and a mutation derived from the same test are not independent observations just because they are named differently. The active gate crosses on three copies of one bit; #7144's alternative crosses on sixteen. Use fresh provenance-disjoint cases or a justified conditional model; retain uncalibrated numbers only as scheduling signals. |

**Priority order.** (1) Improve witness acquisition, not the number of operators: log which pair of still-plausible behaviors a probe would separate, require an authorized observation, and stop if none exists. (2) File only a proposal supported by a particular experience; report what vanishes on deletion. (3) Reuse a different-component, different-repository or different-goal receiver chosen before training. Compare empty/exact/generalized/deleted at equal total budgets, including teacher cost. (4) Finally run the release's native grading conditions (and for code its locked image), keep positive/negative controls and prior checkpoint tests. A failed arm belongs in the denominator. This sequence gives a falsifiable reason to invest in a new mechanism rather than calling an import a breakthrough.
