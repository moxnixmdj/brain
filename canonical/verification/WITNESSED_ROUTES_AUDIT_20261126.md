# What to reuse, what to keep out of the producer

Audit of the active tree and of specific Git objects, **not** a merge recommendation or a claim to have run every branch. A callable on the full checkout can still be absent from the cold worker. The [staging manifest](../tools/stage_harbor_runtime_v1.py) at `d17cb7c1` contains **18 code files + one separately digested empty artifact**. It excludes the research tools, test results, reference solutions, and `.git` of Brain. The 15-file count in the earlier report described an older mount.

## Fifteen named organs, by mechanism

All 15 source modules below exist here. The distinction that matters is what input an operator needs, whether it actually fired and who checked the result. `tools/` means `canonical/tools/`; `swe_kernel/` means `canonical/swe_kernel/`. All listed stems have suffix `_v1.py`.

| Module | What the code does; use or restriction |
|---|---|
| `tools/history_template_repair` | Shapes statement anchors, identifies holes, rebinds tokens. The historical measurement reads pairs of revisions; **not** a blind runtime driver. The shared token instantiator is used by `prior_owned_insertions`: localized path + dotted owner + real preceding statement, only commits reachable from parents of the full receiver HEAD. Tests distinguish base, past, sibling, future and two methods called `f`. |
| `tools/the_failing_run_names_the_expression` | Records live expressions, blames values quoted in a failure message and derives guard candidates. Its historical `repair` driver reads the fix commit and its test. Use the observation primitive after a permitted failing witness, not the driver in a cold room. A quoted value need not be the cause. |
| `tools/the_same_guard_twice_is_the_discriminator` | Fits an operand predicate false at a particular intervened occurrence and true at other admitted occurrences; refuses a vacuous split. A caller must first obtain distinct executions and know which flip helped. Guard operand extraction in the full spine isn't evidence that this fitted predicate fixed a hard case. |
| `tools/the_constant_is_a_hole` | Locates constants and proposes changes using input characters. Called in the full spine's typed-hole path, conditional on a site and observations. Can't supply a semantic requirement or bootstrap arbitrary code from no file. |
| `tools/the_literal_is_the_defect` | Inspects a family of literal changes and corresponding witnesses. The offline experiment includes task-shaped parsing. Do not copy those patterns into the producer as a universal grammar. |
| `tools/the_relation_not_the_value` | Instruments boolean positions, proposes a span-local presence check and grades flips against previously green tests. It explores a particular relation, not all relational programs. Test-commit sweeps are grading/retrospective tools. |
| `tools/arm_learned_from_its_own_verified_repairs` | `fold` takes **(teacher, before, after)**; `propose` emits concrete sources with template IDs. Counts alone did not detect reversed tuple order. The native route now records the winning template/teacher/digest only after the exact candidate restores the receiver's selected test surface. |
| `tools/the_index_is_the_bottleneck` | Scores filing keys for collisions between winning policies on a supplied collection. This is a diagnostic in the memory crystallizer, not an oracle saying what a new caller wants. The new journal looks up only syntax kinds at ranked lines; a hit still has to run. |
| `tools/the_counterexample_is_the_next_experiment` | Chooses discriminating pairs/refinements among known traces. Useful for probe selection; a partition computed from supplied labels is not a live observation. The new browser control instead reads the changed label on a reset page. |
| `swe_kernel/causal_dataflow_graph` | Builds slices and extracts exception frames. In the tested native route it supplies **frame extraction** to localization; this is not dynamic proof of every static dependency edge. |
| `swe_kernel/causal_dependency_repair` | Read-set interventions and replay can attribute a failure along a command/file chain. Full spine has an optional read-set mode. No such chain was established on the two Ansible receivers. |
| `swe_kernel/repair_input_dependency_gate` | Checks loss of parameter slots and non-stdlib imported origins. Native admission calls it before checking a patch. Qualified owners stop `B.f` from silently satisfying `A.f`'s obligation. It remains a syntactic veto, not a proof of input sensitivity. |
| `swe_kernel/verified_lesson_pipeline` | Project-test oracle, measured execution locus, localized application, recheck. Corresponding crystallizer modes require a teacher and test surface. Mere registration, or passing tests without the proposed rule firing, doesn't establish transfer. |
| `swe_kernel/operator_generalization` | Derives and applies operator-swap families with lexical/language gates. Real bounded vocabulary. It cannot generate the two-call edit just by renaming `len`; the execution control distinguishes those cases. |
| `swe_kernel/verified_capability_bridge_index` | Indexes multi-word operations and some producer/artifact/consumer bridges with byte oracles. Can suggest how to acquire a missing supplier. Not arbitrary API discovery, and no network install is licensed in a solve loop. |

The native route, staged route and browser don't get a shared success flag. `UnifiedModel.solve_swe_repo_native` → boundary router → `solve_swe_repo_native_multifile`; `Creature.solve_swe_repo_native` delegates with an external store. `open_model().solve(harbor envelope)` → staged controller → in-room `phase_repair` → **`causal_swe_repair.repair_worktree`**. Both use the same module-local typed-return proposer. Only the former uses the new journal. Staging the entire full-repo route would break the data boundary and reintroduce optional imports. The full model file is **7,402 lines** at `3b8cdeb1`; that isn't a count of working capabilities.

**Version correction.** In a separately inspected [main snapshot `aae7c958`](https://github.com/moxnixmdj/brain/tree/aae7c958b9f37c3067b283aafc3e04e65b3de724/canonical/runtime), `wave40_dark_matter_frontier_kernel_v1` really does declare `FourNetworkGitMemoryEngine`, `ShadowInterfaceHCURouterKernel` and an out-of-core workspace. Those class definitions aren't in the starting checkout. The constructor starts with in-memory state; Markdown persistence does not demonstrate reloading a supported dependency graph. The HCU router's channel costs are estimates; route selection isn't a live action. Wave 41's Rung-3 callback is optional; a callback could call a model, so a module-level `model_calls: 0` would not certify it. We did **not** port or use it. Our default Wave-39 check dispatches an unsolved difficulty-1 subtask with no callback and requires abstention, zero callback invocations, zero model calls.

By a later look at [#7142 at `cb076ff9`](https://github.com/moxnixmdj/brain/tree/cb076ff9a0462f93a6ef03dff8544989f3edb5f9/canonical/runtime), Wave 43/44 had a Git self-seeder, CoW contrast factory, multi-statement anti-unifier, DBSP-like cascade and document-context interface; Wave 45 had a quotient inducer, lineage gate, epistemic record and e-value gate. The seeder's `git log base_commit` includes the base and regex-replaces lowercase identifiers in added lines; that isn't an owner-scoped, executable before/after edit. The cascade accepts explicit dependencies/functions into an in-memory dictionary. `discover_and_route` takes supplied `page_context['tools']` and returns a snippet, not an observed browser execution. Those are genuine implementations of narrower operations, not evidence of official MEME accuracy, cold staged SWE transfer, or OSWorld completion.

At that pin Wave 45's `AntiManufacturedConfidenceMemory.write(..., modality='ASSERTED')` requires two distinct **caller-supplied strings**. It doesn't check two independent executions or verifier identities. Likewise, the active [Wave 39](../runtime/wave39_leapfrog_unification_v1.py) computes a JitRL-like posterior but `partial_route_subtasks` still tries compiled → symbolic → CoW → thresholded optional proposer in that fixed order. Without an explicit verifier it accepts a non-`None` solver result. Its demonstration with injected functions demonstrates **dispatch**, not that the default model implements their answers. The zero-callback abstention was exercised in the clean-checkout suite.
