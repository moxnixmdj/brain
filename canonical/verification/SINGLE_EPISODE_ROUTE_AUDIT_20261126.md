# Does the running agent get the benefit of the code in the repository?

**Short answer: sometimes, through a particular door.** The shortest screen program really ran. The source-room repair cascade did not run just because the full model can name it. This is a source and execution audit, not a capability registration. Compare the [earlier 15-organ audit](WITNESSED_ROUTES_AUDIT_20261126.md), which covers the smaller expression, ownership, test-surface and edit mechanisms. Below are twenty larger candidate mechanisms, not twenty additions to that inventory or twenty solved tasks.

## Which branch work is worth borrowing?

- [#7144](https://github.com/moxnixmdj/brain/pull/7144) was **open/conflicting** at `faea7c31` despite 22 successful head checks. The code provides structured operations: quotient induction, corpus/metamorphic checks, AX-node/batch processing, an anti-manufactured-confidence record, numerical e-processes and tiered memory. In `ingest_fact`, two distinct supplied `source_id` strings can corroborate a hedge; that is not two independent witnesses. `tier1_doc_to_lora_manifest` computes chunk digests, rank and estimated MB, not an adapter or an inference measurement. `compute_e_process` consumes supplied outcomes and a null rate; it doesn't establish the conditional null. The cache/ledger functions don't in themselves start OSWorld. Borrow the quotient and metamorphic checks behind a live port with costs, **not** claimed scores or registrations. [#7145](https://github.com/moxnixmdj/brain/pull/7145) merged the narrower Wave-42 memory work at `ac5c1015`; not the later twelve-engine PR.
- [#6933](https://github.com/moxnixmdj/brain/pull/6933), `f2475632`, open/behind: the site-general expression synthesizer accepts source, function, I/O examples and budgets. Use its bounded generator **after** obtaining a discriminating example from an actual failing call. [#6857](https://github.com/moxnixmdj/brain/pull/6857) `12107c8c` is the complementary ownership experiment; restricting a site can reduce damage without furnishing the missing expression. Neither is evidence of a model-weight update or a novel HARD solve.
- [#7049](https://github.com/moxnixmdj/brain/pull/7049) `baec8e5d`, [#7019](https://github.com/moxnixmdj/brain/pull/7019) `2a32e8a2` and [#7071](https://github.com/moxnixmdj/brain/pull/7071) `eb3cd5e1`: prefer finite distinguishing queries, paired witness controls and machine-read effects respectively. A supplied hypothesis set, a test oracle or an executable file format is a substantial prior. Parts have callers here; these separate conflicting heads aren't one deployed solver.
- [#4723](https://github.com/moxnixmdj/brain/pull/4723) `feaa15e6` and [#4726](https://github.com/moxnixmdj/brain/pull/4726) `5619ab5c`: read-only discovery and test-derived intake can help select a candidate. Calling a module under a known test is not goal-to-effect transfer. [#6605](https://github.com/moxnixmdj/brain/pull/6605) `1f15c2c8` and [#6613](https://github.com/moxnixmdj/brain/pull/6613) `f83cf82b`: resumable life and a first run of an unused capability address liveness; neither supplies the missing behavioral witness by running longer.

**Two executed branch checks.** [Inputs and outputs](../Immediate_Results/nominated_head_controls_20261126_v1.json) · [replay](../tools/reproduce_nominated_head_controls_v1.sh). On the actual #7144 code, sending the *same* hedged observation with labels A, A, alias-for-A yielded `accepted_as_authoritative=false,false,true`. Sixteen copies of one positive bit gave `sup_e=35.527137`, threshold 20 and `anytime_valid_pass=true`. The one-paragraph Tier-1 result was a manifest estimating 4 MB, not 4 MB of learned weights. The controlled results and the normalized import inventory matched in separate exports. On #6933 a chosen `return 0` function with no I/O examples correctly refused. At 1,000 candidate texts, one **or** two examples of squaring yielded no hit. At the author's default 20,000 limit, a single `2→4` yielded six expressions after 1,603 candidates; the first (`x+x`) predicted −6 on −3. Only `x*x` predicted 9. On the declared four-input/six-candidate table the branch's real finite minimax code selected **input 1**, not the already-known 2. One *supplied synthetic oracle* response (1) left `x*x`. With the separately supplied second example `3→9`, the search tested 20,000 texts and also returned just `x*x`. The second observation has to come from somewhere; the algorithm did **not** derive the square specification from the single pair. This is a reason to connect the bounded synthesizer to a truthful, costed question, not to merge its static measurement harness into the blind worker.

**Decision:** keep the full inventory searchable; don't mount reports, gold patches or a 14 MB answer-bearing artifact in the cold room. Route the smallest producer that can ask *one discriminating question* in that room. Log the consumer, self-generated evidence, actual spend and effect, then remove the proposal and try the same receiver. If the only difference is that an API exists, the integration hasn't yet earned credit.
