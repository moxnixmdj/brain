# Evidence Saturation and Minimum Reality Query Law V1

Status: CANONICAL_ACCELERATION_LAW__FAIL_CLOSED_FOR_NEW_FRESH_EVIDENCE_SPEND

## Objective

Minimize newly generated evidence and wall-clock time to truthful terminal ownership without weakening the terminal proof standard.

The controller MUST NOT ask reality a question whose terminal-relevant answer can already be established from admissible existing evidence, deterministic deduction, exact computation, or a previously verified reusable proof.

## Core law

For every proposed fresh experiment, benchmark execution, qualification spend, terminal task, expensive probe, or repeated measurement:

1. Atomize the exact terminal proof obligation.
2. Saturate existing evidence before generating new evidence.
3. Validate provenance, scope equivalence, version/environment binding, independence, contamination, and freshness.
4. Apply deterministic and formal deductive closure.
5. Compile remaining uncertainty into explicit counterfactual worlds and terminal-relevant distinctions.
6. Delete impossible and dominated architectures/actions.
7. Compute the exact minimum reality cut over the remaining distinctions whenever tractable; otherwise decompose until an exact cut is tractable.
8. Execute only observations in that cut, parallelizing independent observations.
9. Compile each new receipt into reusable canonical knowledge so the same information is never purchased twice.

## Evidence universe

Evidence saturation MUST search/reuse, when relevant and allowed by the active information boundary:

- canonical Brain receipts and preserved primary evidence;
- prior executions, artifacts, logs, benchmark runs, verifier receipts and spent failures;
- source code, tests, dependency metadata, commit history and issue/PR evidence;
- official documentation and specifications;
- published benchmark artifacts and datasets;
- papers and reproducible supplementary material;
- independent reproductions;
- trustworthy external public evidence available through current discovery routes.

Existing external evidence is not automatically authoritative. It may close an obligation only when the claim it proves is scope-equivalent or stronger under a justified monotonic relation, with required provenance and independence.

## Closure classes

Each proof obligation MUST reduce to exactly one of:

- EXISTING_EVIDENCE_PASS
- EXISTING_EVIDENCE_FAIL
- DEDUCTIVE_PASS
- DEDUCTIVE_FAIL
- IRREDUCIBLE_REALITY_QUERY
- UNKNOWN_BLOCKED

Simulation, model prediction, or surrogate prediction alone MUST NOT produce capability ownership credit. They may eliminate dominated candidates, estimate likely outcomes, identify uncertainty boundaries, and select the smallest discriminating observation.

## Reality-query admission

A fresh reality query is admissible only if all are true:

- it can change a terminal capability decision or close a required proof obligation;
- no admissible existing evidence already closes the same obligation;
- deterministic deduction cannot close it;
- no cheaper observation closes at least the same terminal-relevant distinctions with no greater evidence risk;
- the query is part of the current exact minimum reality cut or is an already-authorized proof-producing action grandfathered below;
- contamination, authority, resource and information-boundary controls pass.

A query with zero expected terminal decision value is forbidden.

## Dominance

Delete a candidate architecture, mechanism, action or observation if another candidate closes at least the same obligations with:

- no lower verified capability;
- no greater wall-clock cost;
- no greater incremental spend;
- no greater evidence/contamination risk;
- no greater dependency burden;
- no weaker reversibility or verifiability.

## Minimum reality cut

Let U be the set of unresolved terminal-relevant distinctions after evidence saturation and deductive closure. Let each candidate observation cover the distinctions its possible outcomes can resolve.

Select the minimum-cost observation set whose union covers U. Cost ordering is:

1. terminal correctness / admissibility constraints;
2. wall-clock time;
3. incremental spend;
4. compute/resource burden;
5. contamination/evidence risk;
6. observation count.

If an exact cut is computationally intractable, decompose U further. Approximate selection MUST NOT be represented as an exact minimum.

## Compilation rule

Every successful or failed reality query MUST compile into one or more durable artifacts:

- theorem / exact rule;
- exclusion / unsatisfiable region;
- environment fact;
- version-bound compatibility fact;
- failure-class preflight;
- reusable causal mechanism;
- calibrated residual validity envelope;
- stronger behavioral specification.

The same terminal-relevant information MUST NOT be reacquired unless the prior evidence is invalidated by a documented material change.

## Internet and external-data reuse

Existing public data can replace future execution only when the evidence proves the same proposition under the required scope. Version, environment, harness, population, benchmark protocol, and independence differences are material unless a justified equivalence relation proves otherwise.

Discovery evidence may identify a route. Promotion evidence must satisfy the active authority standard.

## Non-regression / current active action

This law MUST NOT delay a proof-producing action that was already independently qualified and has current derived execution authority when this law is activated.

Specifically, the active rank-22 `freecad-spring-clip` one-shot Stage-C execution may proceed under its existing immutable authority chain while this law is installed, provided:

- derived `can_execute=true` remains current;
- exact base/carrier authority remains valid;
- execution budget remains unspent;
- no material state change invalidates its authority.

After that action or any material invalidation, subsequent fresh evidence spend is subject to this law.
