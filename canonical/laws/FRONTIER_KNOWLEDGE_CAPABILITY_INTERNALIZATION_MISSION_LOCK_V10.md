# FRONTIER KNOWLEDGE + CAPABILITY INTERNALIZATION MISSION LOCK V10

Status: CANONICAL / MANDATORY / FAIL-CLOSED

Supersedes V9.

Project Brain may claim capability, benchmark, acceptance, ownership, promotion, real-task, or terminal credit only when the producer cognition path has zero dependencies on another general-purpose model.

Local, remote, open-weight, copied, cached, vendored, self-hosted, wrapped, renamed, or content-addressed models are all model dependencies. Hosting or owning the weight file does not make its reasoning Brain reasoning.

External models may be specimens, comparators, separated evaluators, or non-authoritative knowledge sources, but must not supply load-bearing producer cognition.

A narrow learned artifact may count only when it is itself the internalized Brain capability mechanism, the donor is absent from the target runtime path, full dependency accounting is closed, and no other general-purpose model supplies the target cognition.

Any model-assisted producer result has zero Brain credit regardless of score. Missing or ambiguous cognition provenance also has zero credit.

This invariant overrides every earlier permission for a general cognition model substrate in a Brain-credited producer path. All non-conflicting V9 rules remain in force.
