# Model Non-Dependence Law V1

Status: CANONICAL / MANDATORY

## Core law

Project Brain, Astra, Superheroes, and Super-Workers MUST NOT depend on any language model, frontier model, or pretrained model as the system's brain, cognition source, or mandatory decision loop.

A model is only an optional external knowledge/action source, comparable to:
- web search
- GitHub
- documentation
- databases
- APIs
- Wolfram and solvers
- local files
- browsers and computers
- experiments and simulators
- connected applications
- humans when genuinely necessary

Models may be used only as external sources/tools for specific missing knowledge, transformation, prediction, or action according to the system's objective function. A model MUST NOT supply the planning, decomposition, reasoning, synthesis, judgment, verification, or continuation loop for a cognitive capability that Project Brain claims as its own.

## Mandatory cognitive architecture

The persistent cognitive loop is model-independent:

GOAL
→ RECONCILE CURRENT STATE
→ IDENTIFY CAUSAL FRONTIER
→ DECOMPOSE
→ DETECT MISSING KNOWLEDGE / CAPABILITY / ACTION
→ DISCOVER EXISTING SOURCES AND TOOLS FIRST
→ SELECT BEST ROUTE BY CORRECTNESS, VERIFIED WALL-CLOCK, COST, AND EVIDENCE QUALITY
→ EXECUTE / EXPERIMENT / RETRIEVE
→ VERIFY
→ UPDATE PROJECT BRAIN
→ RECOMPUTE FRONTIER
→ CONTINUE

No step above requires an LLM.

## Knowledge law

Knowledge belongs in Project Brain and durable evidence stores, not inside model weights or a model context window.

If a fact, method, capability, or decision matters, it must be externally recoverable, attributable, and verifiable.

## Tool/source selection law

For every knowledge or action need, the system MUST search and compare available routes before selecting one.

Examples:
- current factual knowledge → web/search/database/API
- exact computation → Wolfram/code/solver
- software capability → repositories/packages/APIs/tools
- UI action → browser/computer
- uncertain hypothesis → experiment/simulation
- synthesis/reasoning → Project Brain's model-independent cognitive loop; model outputs may be consulted only as untrusted external proposals/reference and cannot be part of the credited cognition execution path
- model unavailable/rate-limited → continue through other routes

A model is never privileged merely because it is called AI.

## Search-before-invention law

Search existing tools, repositories, papers, APIs, services, social sources, datasets, and prior Project Brain work before inventing a new mechanism.

Invent only after the relevant search space has been explored to the level justified by expected value and wall-clock cost.

## Persistence law

The Superhero identity, mission, state, causal frontier, evidence, leases, verification status, and continuation loop MUST survive the loss of any model invocation or model provider.

A model call can terminate; the Superhero must continue.

## Runtime implication

Any runtime that places a model call inside the mandatory supervisor loop is architecturally non-compliant and MUST be repaired.

The supervisor is responsible for:
- mission persistence
- state reconciliation
- frontier computation
- source/tool discovery
- route selection
- execution dispatch
- evidence collection
- verification
- Brain update
- continuation

Models are registered only as optional providers in the source/tool registry. For evidence used to acquire or fresh-reuse a cognitive Brain capability, the credited execution path MUST contain no model provider or model artifact; model-assisted runs are component/supplier evidence only.

## Promotion rule

No runtime may be promoted as a real Superhero/Super-Worker if its continued cognition depends on one model, one model provider, or one model context remaining available.

## Objective

Use every available source of knowledge and capability, including models when they are actually best, to reach the verified goal in minimum wall-clock time at hard $0 incremental spend while preserving correctness, evidence, recoverability, and provider independence.
