## Purpose

Acquire existing Opus-5.5-or-better capabilities and internalize their reusable operative configuration into Brain.

## Progress states

1. UNMAPPED
2. EXTERNAL_CAPABILITY_SPECIMEN_FOUND
3. REUSABLE_MECHANISM_IDENTIFIED
4. INTERNALIZATION_IN_PROGRESS
5. BRAIN_CONFIGURED_VERIFICATION_PENDING
6. VERIFIED_OWNED_EQUAL_OR_BETTER
7. REOPENED_BY_REGRESSION
8. UNRESOLVED_THEORY_FALSIFICATION_CANDIDATE

Finding a better model advances at most to EXTERNAL_CAPABILITY_SPECIMEN_FOUND.

## Promotion law

OWNED credit requires:
- external specimen found;
- reusable already-existing capability mechanism/configuration identified;
- operative configuration represented in Brain-owned artifacts;
- external hidden cognition not used as the capability oracle;
- future invocation requires no rediscovery/extraction;
- Brain-configured route itself tested;
- result >= corresponding Opus 5.5 bar;
- durable capability package saved.

## General computation substrate

Models may execute the capability configuration.

A model is a substrate if Brain supplies the operative capability structure.

A model is an external capability provider if Brain's route reduces to "ask this model to do C because it already knows how."

The latter receives no ownership credit.

## Search order

For every target:
1. already-owned Brain mechanisms;
2. skills/procedures/prompts/workflows exposed by existing systems;
3. open-source agent scaffolds and capability libraries;
4. software/tool compositions;
5. published methods/configurations;
6. extractable configuration from accessible systems;
7. external opaque systems only as specimens/evidence sources.

Do not stop at a benchmark-winning model.

## Build boundary

Creating glue that encodes an already-existing mechanism is allowed.

Inventing the underlying capability is forbidden.

## Verification

Verification must exercise the Brain-internalized route.

Evidence about the specimen is existence/discovery evidence only.

## Priority

1. correct internalized capability >= Opus 5.5;
2. permanent Brain ownership;
3. minimum wall-clock to internalization;
4. $0 incremental spend;
5. minimum complexity.
