# What one episode bought: twelve fewer actions, not a new solved task

**26 November 2026 · `arena/92aa8a9e-brain` · local, producer-run evidence.** Brain learned a five-action program from one seventeen-action interaction, saved it to disk, then executed it on a reflected and recolored display. With the same teacher withdrawn it took seventeen actions again. **It did not learn how to solve a different game, a hard coding task, or a previously unanswerable dialogue.** This is a change in the cost of an observed behavior, not evidence for §6, general intelligence, or independent verification.

| Experiment | Strongest result | What did not follow |
|---|---|---|
| Real public ARC-AGI-3 engine, controlled display change | Empty / exact memory / full lifted / shortened / deleted: **17 / 17 / 20 / 5 / 17** actions on the teacher level. Every shortened step and the actual terminal transition confirmed. | **No score gain vs empty**, no extra advance on the real next level or on any of the 24 other game starts. |
| SWE-bench Pro V2 HARD-51, next two prespecified positions | Two completed, **0-byte** agent captures, reproduced from public instructions in fresh source rooms. Calibrated source rewards: **agent 0/2, no-op 0/2, reference 2/2**. | No new image run. Empty output and a broken reference environment are not interchangeable with a verified failure. |
| 401 LoCoMo-Plus triggers against 394 distinct released cues | Unmodified model rejected all 394 writes. After correcting admission and ties, exact cue in top 1 / top 5: **3 / 6 of 401**. | Correct admission did not solve semantic retrieval. The tie change **lost** a top-five hit overall. No answers were generated or officially graded. |
| Single-source compiled repair | A red teacher compiled at rung 2; a renamed red receiver used that rule at rung 0 with **zero proposer calls**. Green receiver left unchanged. | Constructed executable cases, not a cold multi-file repository repair or a calibrated risk guarantee. |

## 1. From a trajectory to five paid actions

The teacher was the **already-known** `lp85-305b61c3` public first level, not a randomly discovered success. The repository's [earlier exploration](canonical/verification/ARC_AGI_3_PUBLIC_EXPLORATION_20261111_V1.json) reached 1/183 public levels with the nearest/effect-prior strategy at 2× budget. For this study we used the [same 50 environment files](canonical/verification/SINGLE_EPISODE_INPUTS_20261126.json), the real offline toolkit on supported Python 3.12, seed 0, and the same cold strategy. **One new acquisition, 17 actions, 0 resets, 0.377 s**. It contained 18 ordered pictures, six different pictures and twelve adjacent unchanged pairs. We exported that [one observed episode](canonical/Immediate_Results/public_screen_one_episode_20261126_v1.json). Repeats reopened it; they did not acquire another teacher.

The policy sees displayed pixels, the legal keys and one click target per same-color connected region. It cannot inspect the game's Python, move to an arbitrary level, read a human replay, or query the engine's private target list. It does receive the actual advance/death signal and a budget. No learned weights or model calls. This is not learning with no priors: the action vocabulary, indexed square displays, nearest explorer, set of eight symmetries, consistent color renaming, observations and reset are engineered. Direction keys retain their public names. Each room has its own synchronous process; the evaluator and game engine are outside that process.

**First experiment, including the negative result.** [Protocol](canonical/verification/FRAME_PROGRAM_TRIAL_20261126.md) · [all 109 scorecards](canonical/Immediate_Results/public_screen_transfer_20261126_v1.json). On the exact original, all four arms advanced in 17. On the transposed, recolored original, empty / raw / lifted / deleted used **16 / 16 / 17 / 16**. Only lifted replay reproduced the whole transformed trace; it was **one action slower** than simply exploring. All four arms failed on the next level and the 24 other starts. Storing a replay with palette-independent signatures was insufficient.

**Second experiment, same teacher.** [Preregistered change](canonical/verification/SCREEN_SLEEP_TRIAL_20261126.md) · [all 130 scorecards](canonical/Immediate_Results/public_screen_sleep_20261126_v1.json). [`file_experience`](canonical/runtime/frame_program_v1.py) builds a graph only from observed `(picture, action, next picture)` edges, keeps terminal state distinct and refuses an observed contradiction. It asks the existing shortest-path routine for a path through that graph. This is **not** the shortest path in the unknown game. It files the resulting guarded program and one teacher dependency in an external SQLite transaction. A new `Creature` reads the currently supported program, calls `UnifiedModel.explore_unknown_environment(..., surface='indexed_screen')`, and tries an action only if surviving alignments agree on an offered target. It checks the very next picture and goal signal. On ambiguity or refutation it stops replaying; a reset after a move is paid before cold exploration resumes. No new generic language-to-game dispatch is implied.

|---|---:|---:|---:|---:|---:|
| Teacher level: paid receiver actions | 17 | 17 | **20** | **5** | 17 |
| Replay steps confirmed there | 0 | 0 | 2 | 5 | 0 |
| Score returned by its game scorecard | 2.7778 | 2.7778 | **2.0069** | **2.7778** | 2.7778 |
| Next level: advances / receiver actions (after 17 preparation actions per arm) | 0 / 76 | 0 / 76 | 0 / 76 | 0 / 76 | 0 / 76 |
| Other 24 starts: advances / actions | 0 / 1,712 | 0 / 1,712 | 0 / 1,712 | 0 / 1,712 | 0 / 1,712 |

The full lifted program made two confirmed moves, hit an ambiguous/unoffered action, paid one reset and used 17 cold actions: **2 + 1 + 17 = 20**. Raw couldn't enter. Shortened revalidated the terminal after its fifth move; the deleted arm returned `UNKNOWN_LOST_SUPPORT` and had no replay. Shortened program **547 B**, raw **1,450 B**, full lifted **1,492 B**; **45,056 B** SQLite file per nonempty treatment, including the logically deleted one. Filing the shortened entry took **17 ms** in the primary run. If the teacher was acquired *solely* for one use, that's **17 + 5 = 22** paid actions versus 17 cold, not a net saving. Two such reuses would amortize the teacher at these observed counts; no evidence that unrelated tasks supply those reuses.

An unchanged screen need not be an unchanged world. In the [hidden-counter negative control](canonical/tests/test_frame_program_v1.py), shortening drops an invisible but necessary `prime`. Actual execution costs `confirm` (fails), `reset`, `prime`, `confirm`: four, not one. Thus filing is a proposal, not a causal certificate. Retraction disables use by this reader; it does not erase the historical bytes. All **130/130** per-room records, including counts of confirmed readbacks, fallback, costs and scorecards, matched on a second consumption and again from a clean checkout and freshly downloaded environments; elapsed times need not match. The [repeat record](canonical/Immediate_Results/single_episode_repeats_20261126_v1.json) hashes these reported fields, not an unrecorded stream of every receiver pixel and input. These repeats check reproducibility, not independent or out-of-distribution generalization.

Same frozen staged controller, new shallow base and private workspace per task. Public instruction and repository only. Candidates frozen at `c135a43a` **before** fetching the release's test surface and reference. Neither the grade nor reference was used to revise either candidate. The experimenter knew the selection; the policy wasn't given the task ID, hidden tests, patch, corpus of earlier results, or another solver. This isolates stages, not human-independent verification.

* **7** (`ea164fdd`): 11,037 instruction chars. Read 6 of 1,457 eligible test bodies (55,952 B); ran four selected suites with **75 + 111 + 13 + 2 passes**, none failing. Repair command 6.108 s; refused without a failing witness.
* **8** (`a1730af9`): 4,691 chars. Read 6 of 269 bodies (47,885 B); the one failing `fetch_url` test did **not** reach the named subject, and one integration file collected no cases. Repair command 8.580 s; refused. Both captures exited 0 with the empty-patch SHA-256. Repeated **producer** setups matched goal/base, source manifests, probe outcomes and captured bytes.

## 3. Language memory: correct storage isn't retrieval

[Protocol locked before scores](canonical/verification/CUE_RETRIEVAL_TRIAL_20261126.md) · [frozen primary grades including misses](canonical/Immediate_Results/cue_retrieval_grades_20261126_v1.json). From all 401 public LoCoMo-Plus pairs we independently sorted the **394 distinct cue texts** and 401 trigger texts by their own hashes. No pair mapping, category, distances, model scores, evidence annotations or answers crossed the producer boundary. The challenge we constructed is to find the original cue in that bank. **Not** long-dialogue placement, a judged answer, an official LoCoMo-Plus grade or proof of the ability to act on the cue.

| Same bank and triggers | Admitted cues | Hits @1 | Hits @5 |
|---|---:|---:|---:|
| Empty | 0 | 0 | 0 |
| Existing lexical BM25 control | 394 candidates | 0 | 1 |
| Original `clm_rrf_memory_op` | **0 / 394** | 0 | 0 |
| Origin translation only | 394 / 394 | 1 | **7** |
| Translation + shared votes for tied scores | 394 / 394 | **3** | **6** |

The original adapter passed `USER_DIRECT` to a bus that recognizes `TRUSTED_USER`; it also treated unrecognized spellings as verifier claims. It now translates known origins, rejects unknowns, and defaults unspecified input to `UNTRUSTED_EXTERNAL`. A commitment binds the declared label; it doesn't authenticate the caller or the truth of the text. The second intervention stops constant ranking channels voting preferentially for lexically earlier record IDs. It is a correctness fix, **not a broad retrieval win**: 4 previously found cues stayed in the top five, 3 fell out and 2 entered. **395/401 missed**. A uniform draw of five distinct IDs from 394 would yield about 5.1 hits in expectation over 401 queries; six hits here are not persuasive evidence of semantic competence. These rows aren't independent draws for an inferential leaderboard comparison.

The primary bank contained 61,211 UTF-8 bytes; origin-only ingest took 0.256 s and its 401 RRF queries took 3.324 s; primary tied ingest/query took 0.325/5.577 s. No model calls, but not zero compute. A clean repeat exposed **five different tied-arm top-five orders**, despite identical scores. Floating sums over hash-randomized token sets were not stable. The [subsequent reproducibility correction](canonical/Immediate_Results/cue_retrieval_stable_20261126_v1.json) used `math.fsum`; three fresh processes matched on every ordered list and retained **3/6**. The original predeclared arms and their instability remain in the record. No tuning of synonyms, category weights or thresholds after seeing the labeled pairs.

## 4. Repair and self-improvement: don't promote a passing check into a law

In the [compiled repair test](canonical/tests/test_compiled_repair_witness_v1.py), the old Futamura cascade edited a receiver whose cases already passed, compiled a replacement that introduced a supplier not bound by the original edit, and let candidate tests share state that the baseline localizer reset. It now refuses green receivers, round-trips teacher edits, retains a new literal as a literal, refuses unbound new names and evaluates each case in fresh globals. These are trusted, constructed single-source cases. A new two-argument function with renamed operands used the verified comparison change at rung 0; no cold proposer or full-repository benefit was measured. `wake_sleep_consolidate` still groups supplied templates and scores. A fork is not a security boundary for arbitrary untrusted code.

Three copies of one pass using a supplied null probability of .25 cross the active gate's .05 threshold. The numerical decision is still possible, but the receipt now explicitly says `false_commit_bound_established=false`. Syntax, tests and mutations selected from the same test aren't independent witnesses. The PR-head controls show the same distinction: on #7144, changing only the label on a duplicate hedged observation made it authoritative; sixteen copies of one bit crossed its separate e-value threshold. On #6933 one known input/output pair admitted **six** disagreeing expressions. A second, deliberately supplied oracle observation selected by the actual finite minimax code distinguished the square from twice the input. **That oracle is the missing resource on a hard task, not an answer the synthesizer already knows.**

The audit found another real default-route fault: caching a live compiled policy by `deepcopy` raised `TypeError` on a module in its namespace. Seven exceptions and two missing-policy assertions occurred in the first mechanism run. Keeping a data template and compiling each copy's own namespace fixed those failures. The combined clean, network-isolated selection then passed **355 tests + 18 subtests**, no skips (two warnings), including live Chromium. This was not the full repository suite; a tracked legacy use-counter increment in the disposable clone was not copied back. Neither this count nor a green guard is a task score.

## Decision

Keep the screen compiler and the memory/repair fixes. **Don't declare a capability promotion or merge on this evidence.** The useful common loop is: acquire a goal-relevant difference, file the smallest supported executable proposal, rebind it to what is *actually offered*, pay for the check and withdraw it when support disappears. The hardest missing piece is still the first one. The next convincing result would be an **independently selected, different-goal receiver** where the generalized arm beats both cold and exact replay on the task's own check, retains unrelated behavior, and loses that advantage on deleting the one teacher, with teacher, resets and failed probes charged. More engines, higher registry counts and a successful call to a named method do not meet that criterion.
