## 5. WHAT WE ARE BUILDING — owner's statement, 2026-10-18 (verbatim intent)

Supplied by the owner after context was lost to condensation. Anchors given: **"$1 million"**
and **"YouTube"**. Neither appears in the repository — this is the missing line.

**The machine must be able to do anything on the computer, by itself.**

- **Learning must be instant.** Not days, not tomorrow. Immediate.
- **Ambitious goals are the point.** Example given: *"Make me a million dollars."* The machine
  must calculate the fastest way, with minimal actions, that actually produces the wanted
  output.
- **It must know when it lacks data, and go get it.** If it needs data it does not have, it
  must by itself say *"I don't have the data, so I must figure out the fastest way to get this
  data"* — and then get it.
- **Prediction requires complete data.** Predicting from partial data extrapolates to *"this is
  the fastest way based only on the data I have"*, when better and faster ways exist that it
  has no data about at all. **It must know literally all the data.**
- **Extrapolation must be global, always.** The owner's own worked example:
  > if the only source it read is a paper saying the fastest way is YouTube videos, it will
  > extrapolate that YouTube is the fastest way. That is a huge mistake. The world is very
  > wide and very big. There are a lot of opportunities everywhere and a lot of hidden
  > opportunities nobody knows about. It must figure out the best way to get all the hidden
  > data, or all the data that it doesn't know, or that is not obvious.
- **Everything must be insanely fast** — including the planning itself.
- **It must not stop short.** If the goal is $1 million, it must not stop at $100. It keeps
  going until the goal is really hit.
- **Totally independent**: keeps planning by itself, all the time.

Owner's words: *"I want it sentient and I want everything instantly. This is what I want."*
