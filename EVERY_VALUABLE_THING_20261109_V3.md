## 3. Three defects found and fixed this round

### Defect 1 — the one model could not reach its own laws (fixed)

`recall()` scored only the 304 knowledge documents. The 781 law records were **stored and never
read.**

```
'a chain that ran no step is not a pass'    -> 0 law hits of 6
'a census that cannot fail is not a gate'   -> 0 law hits of 6
'a report verb is not a source write'       -> 0 law hits of 6
```

Two independent causes:

1. The law rows were never added to recall's corpus.
2. `tokenize()` keeps `_` inside a token, so a law's stem became **one token** —
   `a_census_that_cannot_fail_is_not_a_gate` — which can never overlap a query written in words.

After the fix, asked in the rule's own words: **8 of 8 law queries return the law first.**
Recall over 1,085 documents costs **3.4–6.0 ms median**. Pinned by
`canonical/tests/test_the_model_can_reach_its_own_laws_v1.py` (12 tests).

### Defect 2 — the artifact was stale (fixed)

`test_the_partition_of_the_runtime_tree_is_exact` was failing *before* I touched anything: it
requires **every runtime module to be reachable one way or the other**, and 8 modules — including
all of mine — were in the tree and not in the artifact. Recompiled:
`1956` modules (was 1948), `6703` research records, `308` knowledge documents.
**60 passed, 911 subtests passed, 0 failed.**

### Defect 3 — the model did not report its own blind spot (fixed)

`status()` now returns `reachability` computed from `git ls-files` against the artifact's own
indexes, so the number cannot drift from the truth:
